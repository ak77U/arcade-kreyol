ARCADE KREYOL — KIT DE DÉPART

Contenu :
- index.html : page d'accueil
- style.css : apparence du site
- about.html : présentation
- contact.html : coordonnées
- privacy.html : modèle de confidentialité à adapter

AVANT PUBLICATION :
1. Remplace « Arcade Kreyol » par le nom de ton entreprise.
2. Remplace contact@exemple.com par une adresse que tu contrôles.
3. Ajoute uniquement des jeux que tu as créés ou dont la licence t'autorise la publication.
4. Les cartes de jeux sont des exemples et ne lancent pas encore de jeux.

PUBLICATION GRATUITE AVEC GITHUB PAGES :
1. Connecte-toi sur https://github.com depuis ton navigateur Android.
2. Crée un dépôt public, par exemple arcade-kreyol.
3. Téléverse les fichiers du kit à la racine du dépôt (pas le dossier ZIP lui-même).
4. Ouvre Settings > Pages.
5. Dans Build and deployment, choisis Deploy from a branch, puis la branche main et le dossier /(root), et enregistre.
6. Attends la publication, puis ouvre l'adresse affichée dans Settings > Pages.

Ce kit est un modèle de départ et non un site déjà publié.
